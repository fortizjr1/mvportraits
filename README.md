# MV Portraits

Static HTML/CSS/JavaScript portfolio site for Mario Villanueva Photography.

## Local preview

Open `index.html` directly, or serve the folder with any static server.

## Cloudflare Pages

Connect this GitHub repository to Cloudflare Pages with:

- Framework preset: **None**
- Build command: leave blank
- Build output directory: `/`

Replace the placeholder artwork in `index.html` / `styles.css` with final image assets when ready. The layout is intentionally image-slot based so the content can be swapped without changing the structure.
